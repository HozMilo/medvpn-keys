# medvpn-keys

Публичное зеркало ключей для MedVPN. Раз в 30 минут GitHub Actions читает
канал @freekvn и, если ключи изменились, обновляет `keys.json`.

Приложение берёт файл отсюда:
- https://raw.githubusercontent.com/HozMilo/medvpn-keys/main/keys.json
- https://cdn.jsdelivr.net/gh/HozMilo/medvpn-keys@main/keys.json
